Application Python pour la gestion et l’optimisation de l’irrigation agricole.

# Description
Ce projet implémente des méthodes d’optimisation pour la distribution de l’eau sur plusieurs parcelles.  
Trois approches sont intégrées :
- Méthode graphique : résolution visuelle pour deux variables de décision.
- Méthode du simplexe et dualité** : résolution algorithmique pour des problèmes linéaires plus complexes.
- Validation  : vérification les résultats
